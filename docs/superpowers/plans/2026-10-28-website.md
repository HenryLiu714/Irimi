# irimi website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static landing page plus docs site for irimi in `website/`, with docs generated from `docs/*.md` and `README.md`.

**Architecture:** Astro + Starlight. A Node sync script (`website/scripts/sync.mjs`) runs before `dev`/`build`, turning `docs/*.md` and README sections into Starlight pages (gitignored) and a homepage data file. A custom Astro homepage renders that data in the dark terminal look. Static endpoints serve `llms.txt`, `llms-full.txt` and raw `.md` per page.

**Tech Stack:** Node 22+, astro 7.4.x, @astrojs/starlight 0.42.x, mermaid 12.x (client-side), node:test for unit tests, @playwright/test + @axe-core/playwright for browser tests, linkinator for link checks.

**Spec:** `docs/superpowers/specs/2026-10-28-website-design.md`

## Global Constraints

- `docs/*.md` and `README.md` are read, never edited. `docs/superpowers/` is excluded from the site.
- Body text meets WCAG AA (4.5:1) in dark and light themes, code blocks included. Dark is default.
- GitHub: `https://github.com/HenryLiu714/Irimi`; PyPI: `https://pypi.org/project/irimi/`.
- Site URL is one value, `site` in `website/astro.config.mjs` (placeholder `https://irimi.dev`), read by llms.txt and the agent prompt.
- Install commands copied verbatim from README: `uv tool install --python 3.12 irimi`, `irimi init`, `irimi shadow -- …`.
- `website/` is invisible to ruff, mypy and pytest; no change to Python tooling beyond Makefile targets.
- Generated content (`website/src/content/docs/docs/`, `website/src/data/readme.json`) is gitignored.
- Pinned exact dependency versions in `package.json`; lockfile committed.

## Review Focus

- A README heading the sync script expects is renamed: the build must fail naming the heading, not render an empty section. (Task 2 test `fails loudly on missing section`.)
- Links in docs to anchors (`cli.md#exit-codes`), to files outside `docs/` (`../examples/sidecar/README.md`) and to the README's absolute GitHub docs URLs must all resolve on the built site. (Task 2 tests; Task 5 linkinator run.)
- Phone width (375px): no horizontal scroll on the homepage, including the wide hero terminal block and the tables. (Task 5 test `no horizontal overflow at 375px`.)
- Light theme: the homepage terminal block and tables stay readable when the user toggles light. (Task 5 axe run in both themes.)
- Copy buttons when the Clipboard API is unavailable or denied: no thrown error; the text stays selectable. (Task 4 implementation; Task 5 test with clipboard permission granted checks copied text.)

### Task 2: Sync script

**Files:**
- Create: `website/scripts/sync.mjs`, `website/scripts/lib.mjs`, `website/scripts/lib.test.mjs`

**Interfaces:**
- Produces in `lib.mjs`:
  - `toPage(markdown: string, slug: string, opts: {pages: Set<string>, github: string}) -> {title: string, body: string}`: title from first `# H1`, H1 removed, frontmatter-ready.
  - `rewriteLinks(markdown: string, opts) -> string`: `foo.md` / `foo.md#x` for a known page → `/docs/foo/` (+`#x`); `README.md` in docs → `/docs/`; `../path` → `${github}/blob/main/path`; `${github}/blob/main/docs/foo.md(#x)` → `/docs/foo/(#x)`; external and `#x` links untouched; links inside code fences untouched.
  - `section(markdown: string, heading: string) -> string`: body of the `## heading` section up to the next `## `; throws `Error("README section not found: <heading>")`.
  - `parseTable(markdown: string) -> {head: string[], rows: string[][]}`: first GFM table; throws if none.
  - `firstCodeBlock(markdown: string) -> string`; throws if none.
- Produces from `sync.mjs`: `src/content/docs/docs/<slug>.md` for each `docs/*.md` (`README.md` → `index.md`), `src/content/docs/docs/introduction.md` (README intro paragraphs + "What you get" + "Why"), `src/content/docs/docs/installation.md` (README "Quickstart", "What is supported", "Troubleshooting"), and `src/data/readme.json` `{heroOutput, comparison: {head, rows}, services: {head, rows}}`. Each page gets frontmatter `title` and `sidebar.order`; also writes `src/data/pages.json` `[{slug, title, group, order}]` for sidebar and llms.txt.
